# 1110 — 핵심 인사이트와 문제 정의 다시 세우기

2026-11-10. 4~6주차(인스타그램 Saved)를 정리하고 문제를 다시 정의했다. 아래 인사이트와 문제 정의는 대화에서 에이전트가 쓰고 사용자가 확정한 내용이다.

## 바뀐 방향 (사용자 결정)

- 6주차 가설 "찾던 게시물이 생각한 컬렉션에 없었을 때, 찾은 뒤에도 번거로워 옮기지 않고 그대로 둔다"([../WK06/form.md](../WK06/form.md) 2번)는 납득되지 않아 폐기한다.
- 문제는 **저장 비용**과 **찾는 비용** 두 가지로 본다.
- 저장 쪽: 분류는 실제로 해야 한다. 그래야 찾기 편하다. 초기 세팅(분류별 폴더 만들기)과 저장할 때의 분류는 필요하므로, 분류를 없애는 게 아니라 **분류를 돕는** 방향으로 간다(예: "ㅇㅇㅇ 폴더를 생성할까요?").
- 찾는 쪽: 특정 게시물 상단 고정(핀포인트), 게시물 순서 변경 같은 기능으로 해결한다.

## 핵심 인사이트

1. **분류는 꼭 필요하다.** 주제별로 잘 나눠 둔 사람은 문제없이 찾았다. 찾기 편한지는 분류를 했는지에 달려 있다.
2. **문제는 분류의 필요성이 아니라 분류하는 비용이다.** 사람들은 분류를 안 하고 싶어서가 아니라 귀찮아서 미룬다. 처음에 폴더를 만드는 일과, 저장할 때마다 어느 폴더에 넣을지 고르는 일 모두 부담이다. 그래서 나누지 않고 쌓거나, 기준이 애매한 큰 폴더에 대충 넣는다.
3. **저장할 때 아낀 비용은 찾을 때 더 크게 돌아온다.** 대충 넣은 결과 여러 폴더를 훑어야 하고, 못 찾으면 포기하거나 인스타그램 밖에서 다시 검색한다.
4. **분류를 잘해도 폴더 안에서는 순서를 바꿀 수 없다.** 저장물은 저장한 순서대로만 쌓인다. 자주 보는 것이나 중요한 것을 앞에 둘 수 없으니, 오래된 것은 묻히고 중요한 것도 매번 다시 찾아야 한다.
5. **저장함까지 가는 길도 멀다.** 저장함이 프로필 → 메뉴 안 깊은 곳에 있어, 다시 열기까지 여러 단계를 거친다. 인스타그램이 저장을 다시 꺼내 보게 하는 쪽보다 즉석 소비에 무게를 두는 것과 이어진다(해석). 이 불편을 직접 말한 근거는 아직 1명이라 카드 소팅 · 트리 테스트로 보강한다(사용자 결정으로 세 번째 축에 추가).
6. **사용자는 이미 우회하고 있다.** 꼭 다시 봐야 할 게시물을 나에게 DM으로 보내 두는 것은, Saved 안에 '앞에 꺼내 두는' 수단이 없다는 신호다(해석).

근거는 5주차 인터뷰 답변이다 — [../WK05/deliverables.md](../WK05/deliverables.md).

## 문제 정의

> 사용자는 나중에 다시 보려고 게시물을 Saved에 저장하지만, 폴더를 만들고 매번 고르는 분류 비용이 커서 제대로 나누지 못한다. 다시 보려 할 때는 저장함이 메뉴 깊은 곳에 있어 들어가기부터 멀고, 들어가서도 폴더 안에서 중요한 것을 앞에 둘 수 없어, 필요한 순간 원하는 게시물을 바로 찾지 못한다.

처음 정의는 저장 쪽 · 찾는 쪽 두 축이었고, 같은 날 사용자 결정으로 진입을 세 번째 축으로 넣었다.

| | 문제 | 해결 방향 |
|---|---|---|
| 저장 쪽 (H1) | 분류는 해야 하지만, 처음 폴더를 만들고 저장마다 폴더를 고르는 일이 번거롭다. | 분류를 돕는다 — 저장할 때 맞는 폴더를 제안하거나, "ㅇㅇㅇ 폴더를 생성할까요?"처럼 폴더 생성을 제안한다. |
| 진입 | 저장함이 프로필 → 메뉴 안 깊은 곳에 있어, 다시 열기까지 여러 단계를 거친다. | 저장함을 꺼낸다 — 인스타그램 정보구조에서 저장함의 자리를 다시 정한다(근거: I.A. 카드 소팅 · 트리 테스트). |
| 찾는 쪽 (H2) | 폴더 안이 저장 순서대로만 쌓여, 중요한 게시물이 묻히고 매번 다시 찾아야 한다. | 사용자가 순서를 정하게 한다 — 특정 게시물을 상단에 고정(핀포인트)하고, 게시물 순서를 바꿀 수 있게 한다. |

## HMW

> 분류하는 수고는 덜어 주되 분류는 제대로 되게 하고, 저장함에는 바로 들어갈 수 있게 하며, 필요한 순간에는 중요한 게시물을 바로 꺼내 볼 수 있게 하려면 어떻게 해야 할까?

## 확인할 것

- 폴더를 미리 만드는 초기 비용은 5주차에 인터뷰어가 먼저 꺼낸 보기였고 대상자가 부정했다. 아직 대상자 스스로 말한 근거가 없다.
- Saved 컬렉션 안에서 게시물을 고정하거나 순서를 바꾸는 기능이 정말 없는지 앱에서 확인한다.
