## 1. 휴리스틱 평가 요약

사용자가 자기 계정으로 녹화한 Saved 사용 흐름(① 저장 → ② 새 컬렉션 → ③ 저장함 들어가기 → ④ 둘러보고 찾기 → ⑤ 순서 바꾸기 · 정리, 45초)을 단계마다 닐슨 10원칙에 대었다. 형식은 디자인DB(이모션글로벌) 글 — 계획 → 평가자 결정 → 실행 → 분석, 사용 흐름 단계별로 문제를 찾아 원칙으로 분석. 문제는 원칙 이름으로 적는다.

- 심각도 3: ⑤ 순서 변경 · 고정 없음 [유연하고 효율적인 사용], ① 어디에 넣을지 알려 주지 않음 [기억보단 인식], ⑤ 옮기기 약 10탭 [사용자의 제어 및 자유].
- ③ 저장함 들어가기는 2026-11-17에 고쳤다: 탐색 탭 오른쪽 위에 저장됨으로 가는 아이콘이 있다(사용자 캡처). 뎁스는 줄어 있지만 이름 없는 아이콘이라 모르는 사람이 많을 것이다(사용자 판단). '설정 화면 안' [시스템과 현실의 일치성]을 3 → 2로 낮추고, '지름길이 이름 없는 아이콘' [기억보단 인식] 2를 더했다(심각도는 에이전트 제안).
- 문제는 흐름의 양 끝에 몰린다. 저장할 때는 어디에 들어갔는지는 알려 주지만(저장됨 · 보기 안내) 어디에 넣을지 판단을 돕지 않는다. 다시 꺼낼 때는 앞에 둘 수단이 없다. 그 사이는 지름길이 있지만 알아보기 어렵다.
- 녹화 · 캡처로 고친 것: 저장 버튼만 눌러도 컬렉션 창이 뜬다(도움말의 '길게 누르기'와 다름). 저장됨 안에 검색이 있다. 저장 뒤 '컬렉션이름에 저장됨 · 보기' 안내가 뜬다.
