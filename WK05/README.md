## 과제

기존 서비스 중 개선하고 싶은 서비스를 선택하고, 그 서비스의 문제에 대한 가설 체인을 만든다.
이때 파이 커뮤니티처럼 너무 쉽게 접근 가능한 서비스는 제외한다.

지난 주차까지 가설을 수직·수평으로 넓히고, 기준을 가지고 가설을 선택하는 것까지 모두 진행했다.
이번에는 자신이 선택한 문제가 실제로 사용자에게서 발생하는 문제인지 검증할 수 있는 인터뷰를 진행한다.
인터뷰를 잘 할 수 있는 팁은 디스코드로 자료가 공유된다.

### 이번 주차에 해야 할 것

- 가설 검증에 맞는 사용자 정의를 잘해서 찾기
- 편향 없이 사용자 데이터 모으기
- 데이터를 통해 가설 검증 여부 판단하기

### 산출물

- 사용자 선정 기준
- 검증 여부 판단 기준
- 판단의 근거가 되는 인터뷰 답변

### 측정하고 강화할 역량

- 자신이 찾은 문제를 겪는 사용자를 잘 정의하고 찾는 것
- 편향 없이 중립적으로 인터뷰 질문 설계하기(순수한 데이터 모으기)
- 인터뷰 답변을 잘 해석하기(세운 가설이 맞는지 아닌지 판단하기)
