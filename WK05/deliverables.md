# 5주차 산출물 초안 — 인스타그램 저장(Saved) 가설 검증

2026-10-11 인터뷰 5명을 정리한 초안이다. 근거 자료는 클로바노트 녹취 두 개와 인터뷰어 메모다. 녹취는 대상자 실명이 들어 있어 저장소에 넣지 않았다.
판정은 에이전트가 녹취와 메모를 읽고 낸 초안이고, 사용자 확인 전이다. 대상자 이름은 P1~P5로 바꿨다.

검증할 가설은 4주차 선택 체인이다([../w4/](../w4/)).

> 현상 — 사용자는 관심사별로 쌓아 둔 저장물에서 필요한 것을 골라내지 못해, 처음부터 하나씩 눌러 확인한다
> ← A 저장물에 '무엇이 왜 쓸모 있었는지'가 남지 않는다
> ← A-1 저장은 게시물 통째로 되는데, 쓸모는 그 안의 한 부분이다
> ← A-1-a(근본 원인) Saved는 '보관'만 한다 — 그 부분과 맥락을 덧붙일 자리가 없다

## 2. 검증 여부 판단 기준

4주차 확인 계획(2026-10-06, 인터뷰 전에 씀)의 '맞다면 · 틀리다면'을 판정 규칙으로 옮겼다. 규칙을 글로 정리한 것은 인터뷰 뒤지만, 내용은 인터뷰 전에 정한 것이다.

### 근거로 세는 답변

| 구분 | 무엇 | 판정에서 |
|---|---|---|
| **유효** | 대상자가 스스로 말한 자신의 지난 행동·경험 | 센다 |
| **유도** | 가설이나 답이 들어간 질문에 "네", "맞아요"로만 답한 것 (예: "찾기가 좀 어렵지 않나요?" → "맞아요. 어렵습니다.") | 세지 않는다. 기록만 남긴다 |
| **참고** | 다른 사람의 행동을 추측한 말, 해법에 대한 반응, 선정 기준 밖 대상자의 말 | 세지 않는다. 새 가설의 단서로만 쓴다 |

### 판정 단계

| 판정 | 조건 |
|---|---|
| **지지** | 판정 대상 4명 중 2명 이상에게서 유효 답변으로 나오고, 그중 디자인이 아닌 관심사로 저장하는 사람이 1명 이상 있다. 반대 사례가 없거나, 있더라도 조건으로 설명된다 |
| **조건부 지지** | 특정 조건(예: 컬렉션이 없거나 기준이 애매할 때)에서만 나오고, 조건이 다르면 반대로 나온다 |
| **근거 없음** | 가설과 관련된 유효 답변이 나오지 않았다. 질문이 이 부분에 닿지 않았다는 뜻이며, 기각은 아니다 |
| **기각** | 유효 답변 2명 이상이 가설과 반대되는 행동을 말한다 |

### 4주차 계획에서 가져온 가설별 기준

- **A · A-1:** 다시 찾을 때 떠올린 단서가 관심사와 상관없이 '부분'(장면 · 색 · 곡)이어야 지지다. 계정명이나 썸네일만으로 금방 찾는다는 답이 많으면 A-1을 내려놓고 C를 다시 본다.
- **A-1-a:** 그 부분을 스크린샷이나 메모 등 인스타그램 밖에 따로 남겨 대신하는 행동이 나와야 지지다.
- **범위:** '부분'이 디자이너에게서만 나오고 다른 관심사에서 나오지 않으면 문제의 범위를 다시 좁힌다.

## 3. 판정과 근거가 되는 인터뷰 답변

### 요약

| 가설 | 판정(초안) | 한 줄 |
|---|---|---|
| 현상 — 골라내지 못하고 하나씩 확인 | **조건부 지지** | 기준이 애매한 컬렉션을 가진 사람은 못 찾고 여러 폴더를 훑는다. 주제별로 잘 나눈 사람은 잘 찾는다 |
| A — 무엇이 왜 쓸모 있었는지 남지 않음 | **근거 없음** | 찾을 때 무엇이 떠올랐는지 묻지 않았다 |
| A-1 — 쓸모는 게시물의 한 부분 | **근거 없음** | 장면 · 색 · 곡 같은 '부분'을 말한 사람이 없다. 나온 쓰임(따라 하기, 코디 참고, 장소 찾기)은 게시물 전체에 가깝다 |

| A-2 — 저장할 때는 쓸 곳이 정해져 있지 않음('언젠가') | **지지** | 4명 모두 일단 저장하고, 목적이 생기면 다시 찾는다 |
| B — 한 컬렉션에 서로 다른 주제가 섞임 | **지지** | 섞인 사람(P4)은 헤매고 나눈 사람(P3)은 잘 찾는다. 분류 방식이 결과를 가른다 |
| B-1 — 저장 순간에 세부 분류를 하면 흐름이 끊김 | **조건부 지지** | 분류하는 수고를 이유로 나누지 않는다(P2 · P5) |
| B-2 — 넣은 뒤에는 다시 나누거나 옮기기 어려움 | **지지** | 옮기는 게 번거로워 폴더를 하나 더 훑는다(P4), 폴더 안에 폴더가 필요하다(P5) |
| C — 썸네일 · 저장 순서로는 알아볼 수 없음 | **근거 없음 (반대 쪽 사례 1)** | P4는 썸네일에 적힌 지역명을 훑어서 찾는다 |

**결론(초안):** 선택한 체인(A → A-1 → A-1-a)은 이번 인터뷰로 검증되지 않았다. 반증된 것이 아니라 이 질문에 닿는 답이 나오지 않았다.
대신 B 갈래(분류 기준이 애매하고, 넣은 뒤에는 고치기 번거롭다)가 관심사가 다른 여러 대상자에게서 반복해 나왔다. 이 갈래는 4주차 첫 버전(2026-10-04)에서 선택했던 근본 원인 "분류가 '저장하는 순간, 컬렉션 한 단계'에서만 된다"와 같은 방향이다.
