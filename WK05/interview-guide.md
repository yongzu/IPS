# 5주차 인터뷰 가이드 — 인스타그램 저장(Saved)

인터뷰 대상자가 가설에 맞춘 답을 하지 않도록 쓴 가이드다. 질문에는 가설에 나오는 말(찾기 어렵다, 부분, 맥락, 정리, 메모)을 쓰지 않는다. 대상자가 그 말을 먼저 꺼내면, 그때 대상자가 쓴 말 그대로 이어서 묻는다.

- 시간: 20~25분 · 1명씩
- 방식: 대면이면 대상자가 자기 휴대폰으로 인스타그램을 열어 보여 준다. 원격이면 화면을 공유한다. 기억으로 말하는 것보다 실제 화면을 보면서 묻는 쪽이 편향이 적다.
- 기록: 동의를 받고 녹음한다. 답변은 요약하지 말고 대상자가 한 말 그대로 적는다.
- 4주차 가설 체인: [../w4/](../w4/). 6절의 질문-가설 표는 인터뷰어만 보고, 대상자에게 보여 주지 않는다.

---

## 1. 지킬 것

1. **지난 일을 묻는다.** "보통 어떻게 하세요?", "~하면 쓰시겠어요?"보다 "가장 최근에 ~했던 때"를 묻는다. 가정을 묻는 질문은 대상자의 희망을 듣게 되고, 실제로 한 행동은 들을 수 없다.
2. **보여 달라고 한다.** "그때 어떻게 했는지 지금 그대로 해 보여 주실 수 있어요?"
3. **열린 질문으로 묻는다.** 예/아니오로 답하는 질문을 피하고 무엇을, 어떻게, 왜를 묻는다.
4. **대상자의 말을 받아 다시 묻는다.** "방금 '○○'라고 하셨는데, 조금 더 얘기해 주세요."
5. **침묵을 채우지 않는다.** 답이 끊겨도 3~5초 기다린다. 예시 답을 먼저 주지 않는다.
6. **반응하지 않는다.** "맞아요, 저도 그래요", "좋네요"처럼 맞장구치지 않는다. "그렇군요", "그다음엔요?"만 쓴다.
7. **가설과 해법을 말하지 않는다.** 인터뷰가 끝날 때까지 내가 무엇을 확인하려는지, 무엇을 만들려는지 말하지 않는다.

## 2. 하지 말 것 — 고쳐 쓴 예

| 하지 말 것 (유도) | 이렇게 묻는다 |
|---|---|
| 저장한 거 다시 찾기 어렵지 않으세요? | 저장해 둔 걸 다시 열어 본 가장 최근 일을 얘기해 주세요. |
| 게시물 중에 특정 부분 때문에 저장하시죠? | 이건 무엇 때문에 저장하셨어요? |
| 저장할 때 메모를 남길 수 있으면 쓰시겠어요? | 저장한 다음에 이 게시물로 따로 하신 게 있어요? |
| 컬렉션이 뒤죽박죽이지 않아요? | 이 컬렉션에 뭐가 들어 있는지 설명해 주세요. |
| 썸네일만 보고는 모르겠죠? | 그중에서 그게 그거라는 걸 어떻게 알아보셨어요? |
| 스크린샷도 찍어 두시죠? | 인스타그램에서 본 걸 나중에 다시 보고 싶을 때 어떻게 하세요? |
| 정리가 안 돼서 불편하시죠? | (묻지 않는다. 대상자가 먼저 말하면 그 말로 이어서 묻는다.) |

## 3. 대상자 선정

- 인스타그램을 지금 쓰고 있고, 저장(Saved)을 한 번 이상 다시 열어 본 적이 있는 사람.
- 관심사가 다른 사람을 섞는다. 디자인 레퍼런스를 저장하는 디자이너와 함께, 디자인이 아닌 관심사(화장법·화장품, 패션, 아이돌, 음악, 요리, 운동 등)로 저장하는 사람을 꼭 포함한다. 가설이 관심사가 달라도 성립하는지가 핵심이다.
- 저장물이 많은 사람과 적은 사람을 섞는다. 저장물 수는 인터뷰 중 화면을 보고 적는다.
- 4주차 가설 체인(피그잼 보드나 IPS 페이지)을 본 사람은 되도록 피한다. 이미 본 사람과 인터뷰했다면 기록에 표시한다.
- 섭외할 때는 "인스타그램 쓰는 방식에 대해 20분 정도 얘기를 듣고 싶다"고만 말한다. "저장 기능의 불편함" 같은 말은 꺼내지 않는다.

## 4. 진행 순서

### 0. 도입 (2분) — 그대로 읽는다

> 오늘은 인스타그램을 평소에 어떻게 쓰시는지 듣고 싶어서 연락드렸어요. 맞는 답이나 틀린 답은 없고, 평소에 하시는 그대로 말씀해 주시면 돼요. 저는 인스타그램을 만든 사람이 아니라서, 좋았던 것이든 별로였던 것이든 편하게 말씀해 주세요. 중간에 화면을 같이 볼 수 있게 인스타그램을 열어 주실 수 있을까요? 기록을 위해 녹음해도 괜찮을까요?

### 1. 인스타그램 사용 전반 (3분) — 몸풀기

- 인스타그램에서 주로 무엇을 보세요?
- 가장 최근에 인스타그램을 열었을 때 무엇을 하셨어요?

### 2. 나중에 다시 보고 싶은 걸 만났을 때 (4분) — 저장 기능을 꺼내기 전에 묻는다

- 인스타그램에서 보다가 나중에 다시 보고 싶은 걸 발견하면 어떻게 하세요?
  - 대상자가 말한 방법이 하나라도 나오면: "그 방법을 가장 최근에 쓴 때를 얘기해 주세요."
  - 다른 방법이 더 있는지: "그것 말고 또 있어요?" (예시를 주지 않는다)
- 대상자가 저장(Saved)을 말하지 않으면 그때 처음 꺼낸다: "인스타그램의 저장 기능도 써 보셨어요?"

### 3. 저장하는 순간 (4분) — 화면을 보면서

- 저장한 게시물 목록을 같이 볼 수 있을까요? 가장 최근에 저장한 걸 하나 열어 주세요.
- 이건 무엇 때문에 저장하셨어요?
  - 대상자가 무언가를 짚으면: "그게 이 게시물의 어디에 있어요? 보여 주실 수 있어요?"
- 저장할 때 무엇을 하던 중이었어요?
- 저장할 때 어디에 넣으셨어요? 왜 거기에 넣으셨어요?
- 저장한 다음에 이 게시물로 따로 하신 게 있어요?

### 4. 다시 꺼내 본 순간 (7분) — 핵심

- 저장해 둔 걸 다시 열어 본 가장 최근 일을 떠올려 주세요. 그때 무엇을 하던 중이었어요? 왜 열게 됐어요?
- 그때 어떻게 찾아갔는지 처음부터 순서대로 얘기해 주세요. 지금 그대로 해 보여 주실 수 있어요?
- 찾으러 들어갈 때 머릿속에 무엇이 떠올라 있었어요?
- 그중에서 그게 그거라는 걸 어떻게 알아보셨어요?
- 찾기까지 몇 개쯤 열어 보셨어요? 시간은 얼마나 걸렸어요?
- 결국 어떻게 됐어요? 찾은 다음에 그걸로 무엇을 하셨어요?
  - 대상자가 게시물의 어딘가를 짚으면: "그걸 어떻게 쓰셨어요?"
- 그 게시물은 언제쯤 저장하셨는지 기억나세요?
- 저장해 둔 걸 다시 열어 본 다른 일도 있었어요? 그때는 어떻게 됐어요? (두세 번 반복할 수 있다)
  - 대상자가 찾지 못한 경험을 먼저 말하면: "그때 어떻게 하셨어요?", "그다음엔요?"

### 5. 저장물 전체 (3분) — 화면을 보면서

- 저장한 게 전부 몇 개쯤 될까요? 컬렉션은 몇 개 있어요? (화면을 보고 적는다)
- 가장 많이 쌓인 컬렉션 하나를 열어 주세요. 여기 무엇이 들어 있는지 설명해 주세요.
- 컬렉션은 어떻게 나누게 되셨어요?

### 6. 마무리 (2분)

- 저장 기능에 대해 더 하고 싶은 얘기가 있으세요?
- 제가 묻지 않았는데 중요하다고 생각하시는 게 있을까요?

> 오늘 말씀 감사합니다. (인터뷰가 끝난 뒤에는 대상자가 물으면 이번 과제의 주제를 설명해도 된다.)

## 5. 기록 시트 — 대상자마다 한 장

| 항목 | 기록 |
|---|---|
| 대상자 | 이니셜 · 관심사 · 가설 체인을 본 적 있는지 |
| 저장물 · 컬렉션 | 대략 개수 · 컬렉션 이름 |
| 나중에 다시 보려고 쓰는 방법 | 대상자가 스스로 말한 것만 원문으로(저장 · 스크린샷 · DM · 링크 복사 등) |
| 최근 저장 1건 | 저장한 이유(원문) · 짚은 곳 · 저장 뒤 한 일 |
| 다시 꺼낸 일 1 | 상황 · 떠올린 것(원문) · 알아본 단서 · 열어 본 개수 · 걸린 시간 · 찾음/포기 · 찾은 뒤 쓴 것 · 저장 시점 기억 |
| 다시 꺼낸 일 2~3 | 같은 항목 |
| 가장 큰 컬렉션 | 들어 있는 것에 대한 설명(원문) |
| 대상자가 먼저 꺼낸 말 | 불편, 포기, 우회 등 묻지 않았는데 나온 말(원문) |

## 6. 질문 → 가설 (인터뷰어만 본다)

| 질문(4절 번호) | 확인하는 가설 |
|---|---|
| 2. 나중에 다시 보고 싶을 때 하는 방법 | A-1-a — 저장 말고 다른 곳(스크린샷 · 메모 앱 등)에 따로 남기는지. 묻지 않았는데 나오는지가 중요하다. |
| 3. 무엇 때문에 저장했는지 · 어디에 있는지 | A-1 — 저장 이유가 게시물 전체인지, 그 안의 일부인지 |
| 3. 저장한 다음에 따로 한 것 | A-1-a · A-2-a — 이유나 일부를 다른 곳에 남기는지 |
| 4. 머릿속에 떠올라 있던 것 | A — 기억한 단서가 장면·색·곡 같은 일부인지, 계정·전체 인상인지 |
| 4. 어떻게 알아봤는지 | C — 썸네일·순서로 알아봤는지 |
| 4. 열어 본 개수 · 시간 · 찾음/포기 | 현상 — 하나씩 눌러 확인하는지 |
| 4. 찾은 뒤 쓴 것 | A-1 — 실제로 쓴 것이 전체인지 일부인지 |
| 4. 언제 저장했는지 기억 | C-2 — 기억하는 것이 '언제'인지 '무엇'인지 |
| 5. 가장 큰 컬렉션 설명 | B — 한 컬렉션에 주제가 몇 개 함께 있는지 |
| 5. 컬렉션을 나눈 방식 | B-1 |

가설이 맞는지 틀리는지 판단하는 기준(검증 여부 판단 기준)은 별도 문서로 쓴다. 판단 기준은 답변을 보기 전에 정해 두어야 답에 맞춰 기준을 바꾸지 않게 된다. 질문은 첫 인터뷰 뒤에는 바꾸지 않는다.
