# 1124 다시 찾는 저장, 해결 아이디어 50

2026-11-24. 페이지: https://yongzu.github.io/IPS/1124/

- 사용자 지시: 인터뷰 결과와 다른 저장, 아카이빙 플랫폼 조사를 바탕으로 해결 아이디어(방법론) 10가지를 리스트업하고, 시각화와 설명을 피그마가 아닌 IPS 웹페이지로. 시각화는 릴스에서 저장하는 방법과 저장된 컬렉션 레이아웃을 보여 주는 화면 흐름.
- 추가(같은 날, 사용자 지시): "10개가 너무 빨리 나왔다, 같은 층위로 40개 더". 아이디어 11~50을 같은 틀(한 줄 설명, 단계, 대상, 근거 강도, 빌린 곳과 출처, 어떻게 3줄, 조심할 점, 확인 방법, 릴스에서 시작하는 세 화면)로 더했다. 저장 11~21, 탐색 22~36, 관리 37~50. 플랫폼 14곳 더 읽음(Telegram, Facebook 저장, Spotify, Google 지도, 네이버 지도, Gmail, Slack, Readwise, 카카오톡 톡서랍, Airbnb, Arc, Goodreads, X 북마크, Google 포토 추억). 단계 거르기 버튼.
- 데스크 리서치(같은 날, 사용자 지시): 정량 근거가 비어 있어 논문, 아카이빙 플랫폼, 현업 UXUI, 디자인 방법론 30편을 읽고 07장으로 맨 아래에 붙였다. 형식은 Phi Brain IPS 페이지의 연구 카드(번호, 주장, 제목, 누르면 출처, 대상과 방법, 프로젝트 역할, 핵심 내용, 인사이트, 도식, 원문). 묶음 A 다시 찾기와 기억, B 정리 비용, C 쌓임과 다시 안 봄, D 인스타그램과 플랫폼 데이터, E 현업 UXUI 원칙, F 디자인 방법론. 끝에 "Think" 7가지와 정량 공백을 채우는 순서 5가지. 페이지 구조는 바꾸지 않음(사용자 지시). 파일 `research.js`.
- 구성: 01 지금까지(인터뷰 판정), 02 다른 저장 플랫폼 11곳(인스타그램, Pinterest, Are.na, mymind, Cosmos, Raindrop.io, iOS 18 사진, Google 포토, TikTok, YouTube, Pocket), 03 아이디어 한눈에(단계, 근거, 대상 표), 04 아이디어 10가지(아이디어마다 릴스에서 저장, 저장 직후, 저장함에서 찾기 세 화면), 05 먼저 시험할 조합과 다음 검증, 06 출처.
- 아이디어: 01 지금 저장, 나중에 정리 / 02 보고 고르는 저장 시트 / 03 끌어서 바로 넣기 / 04 곧 볼 것 / 05 앞에 두기, 하트와 고정 / 06 저장 무렵으로 찾기 / 07 장면까지 보이는 미리보기 / 08 글로 찾기 / 09 큰 컬렉션 안의 섹션 / 10 목적이 생기면 모으기.
- 아이디어, 근거 강도, 조합은 에이전트 제안(사용자 확인 전). 출처는 2026-11-24 웹 검색, 홍보 글과 리뷰가 섞여 있다.
- 파일: `index.html`(본문, 플랫폼 카드, 출처), `ideas.js`(그리기 도구, 아이디어 1~10, 한눈에 표, 거르기), `ideas-more.js`(아이디어 11~50 데이터), `ideas.css`.
